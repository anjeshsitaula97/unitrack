# Tests

## Running Tests

```bash
npm run test
npm run test:watch  # Watch mode
npm run test:coverage  # With coverage
```

## Test Structure

- `src/lib/__tests__/` - Unit tests for library functions
- Add API route tests in `src/app/api/**/__tests__/`
- Add component tests in `src/**/__tests__/`

## Adding Tests

```bash
npm run test     # Run once
npm run test:watch  # Watch mode
```
