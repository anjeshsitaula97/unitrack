Single-file Prisma schema (`schema.prisma`) declares ~50 models covering university/course/application management, student records, HR (attendance, leave, payroll), chat, tickets, learning resources, and system settings. The datasource targets SQLite via `DATABASE_URL` with the client generated in library mode (`engineType = "library"`). Relationships are expressed declaratively using `@relation`, explicit `onDelete` cascade rules, and `@@index`/`@@unique` constraints on frequently queried or business-key columns. Seed utilities (`seed-roles.ts`, `seed-activities.ts`, `seed-notifications.ts`, `seed-universities.ts`) import the generated `@prisma/client`, instantiate a single `PrismaClient`, perform idempotent upserts keyed by a unique field, and disconnect in a `finally` block. A dump helper (`dump-roles.ts`) exports current role data as JSON, and `check-counts.ts` verifies record counts across key tables. Runtime database files (`dev.db`, `._dev.db`) are checked in to support local development without an external server.
