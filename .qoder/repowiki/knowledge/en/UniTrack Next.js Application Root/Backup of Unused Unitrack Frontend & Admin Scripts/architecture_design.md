This is a snapshot of an older version of the Unitrack app kept under `.backup_unused/` to preserve code that was later removed from the main project. It contains a full Next.js-style source tree under `src/`: feature modules organized by domain (dashboard, hr, courses, universities, etc.) each exposing a `<XxxContent>` component under `src/app/<feature>/components/`, shared layout components (`AppLayout`, `Sidebar`, `Topbar`) in `src/components/`, and a small shared library in `src/lib/` (Prisma client singleton in `db.ts`, seeders, crypto, notifications, etc.). The top-level files are standalone Node/TS scripts: `enable-wal.js` enables SQLite WAL mode via Prisma raw SQL, `image-hosts.config.mjs` exports allowed image hostnames, and the `scratch_*.ts` files are ad-hoc Prisma scripts for seeding an admin user, cleaning duplicate users, and testing delete/update operations. There is no build manifest inside this directory — it is consumed as-is by running the scripts directly with Node/ts-node against the workspace's Prisma schema.
