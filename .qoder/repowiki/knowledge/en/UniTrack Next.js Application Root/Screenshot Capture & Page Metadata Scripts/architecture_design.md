The module contains three independent CLI-style Node scripts with no shared library code:
- `capture-realshots.mjs` and `screenshots.mjs` are Puppeteer-based automation scripts that launch a headless Chromium instance, log in to `http://localhost:4028` using hardcoded credentials, navigate to a curated list of routes (via direct `page.goto` or sidebar click), wait for client-side navigation, and write full-page PNGs to `public/screenshots/<name>.png`. `screenshots.mjs` additionally creates an isolated `BrowserContext`, overrides camera permissions for face-enrollment pages, and uses a larger route table covering HR, settings tabs, university/course/student modules, reports, tickets, analytics, etc.
- `add-metadata.js` is a one-off filesystem transformer: it recursively walks `src/app` looking for `page.tsx` files, skips those already exporting metadata or marked `'use client'`, resolves a human-maintained title map keyed by relative path, and injects an `export const metadata = { title, description }` block after the last import statement.
Dependency direction is outward-only: scripts depend on Puppeteer and Node built-ins (`fs`, `path`, `url`) and operate against a live dev server plus the local source tree; there are no imports between these scripts.
