A single Next.js 16 project whose source tree is split into logical child modules: `shared_lib` provides server-side middleware, JWT/session handling, Prisma client access, and feature configs consumed by pages; `shared_components` supplies the app shell (layout, sidebar, topbar) and reusable UI primitives used across routes; `styles_assets` centralises Tailwind theme, global CSS, and static assets (images, TensorFlow face-recognition models); `database_schema` holds the Prisma SQLite schema and seed scripts invoked via `prisma seed`; `scripts` contains Puppeteer-based screenshot capture and page-metadata injection tooling; `graphify_output` is generated analysis output; `backup_unused` archives legacy Unitrack frontend/admin code. Cross-child wiring happens through the root `next.config.mjs` (which configures headers, CSP, remote image hosts from `image-hosts.config.mjs`, and marks `@prisma/client`/`prisma` as server-only), `tsconfig.json` for path aliases, and `vitest.config.mjs` for test discovery. All children are imported directly by Next.js routes or by each other — there is no separate build orchestrator beyond the standard `next dev|build|start` commands in `package.json`.
